# Доказательная библиотека thecbd.ru

Рынок: Россия. Язык: русский. Сначала переработка 135 существующих статей, затем новые материалы. Цель — интересные и коммерчески полезные статьи, где обещания соответствуют доказательствам.

Основной бизнес-результат: целевой SEO-трафик и продажи. Стратегия — docs/seo-sales-strategy.md. Накопление знаний и обновление правил — docs/knowledge-maintenance.md.

Каталог содержит 49 материала: медицинские источники, базы исследований и коммерческие ориентиры. Статусы проверки указаны отдельно; наличие ссылки не означает подтверждение всех её утверждений.

## Порядок работы
1. Читать AGENTS.md и docs/editorial-policy.md перед каждой задачей.
2. Найти источники в sources/catalog.csv и проверить их актуальность.
3. Для ключевых медицинских тезисов заполнить templates/claim.md и templates/study.md.
4. Подготовить статью по templates/article.md и пройти docs/workflow.md.
5. Обновить migration/articles.csv и CHANGELOG.md.

Библиотека не является завершённым систематическим обзором. Реестр 135 статей пока содержит пустые позиции, а не подтверждённый список URL. Проверка регистрации товаров и применимости рекламных формулировок в РФ ещё не выполнена.

В новом чате передавайте ссылку на этот репозиторий и просите прочитать AGENTS.md: автоматическая загрузка библиотеки и постоянная память между чатами не гарантируются.
